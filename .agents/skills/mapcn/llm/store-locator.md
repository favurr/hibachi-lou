# Store Locator

Searchable store list synced with map markers.

Type: `registry:block`
Registry item: <https://mapcn.dev/r/store-locator.json>

## Install

```bash
npx shadcn@latest add @mapcn/store-locator
```

## Dependencies

- lucide-react

## Registry Dependencies

- @mapcn/map
- input
- sidebar
