# Analytics Card

Compact analytics card with a headline metric over a world map.

Type: `registry:block`
Registry item: <https://mapcn.dev/r/analytics-card.json>

## Install

```bash
npx shadcn@latest add @mapcn/analytics-card
```

## Dependencies

- lucide-react

## Registry Dependencies

- @mapcn/map
- card
- badge

## Files

- src/registry/blocks/analytics-card/page.tsx -> app/analytics-card/page.tsx (registry:page)
- src/registry/blocks/analytics-card/data.ts -> app/analytics-card/data.ts (registry:component)
