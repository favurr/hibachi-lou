# Analytics Map

Real-time analytics overview with a world map, breakdown cards, and device stats.

Type: `registry:block`
Registry item: <https://mapcn.dev/r/analytics-map.json>

## Install

```bash
npx shadcn@latest add @mapcn/analytics-map
```

## Dependencies

- recharts
- lucide-react

## Registry Dependencies

- @mapcn/map
- card
- chart

- src/registry/blocks/analytics-map/components/overview-card.tsx -> app/analytics/components/overview-card.tsx (registry:component)
- src/registry/blocks/analytics-map/components/breakdown-card.tsx -> app/analytics/components/breakdown-card.tsx (registry:component)
