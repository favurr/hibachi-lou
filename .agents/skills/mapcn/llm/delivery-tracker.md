# Delivery Tracker

Live order tracking with route progress, courier position, and order details.

Type: `registry:block`
Registry item: <https://mapcn.dev/r/delivery-tracker.json>

## Install

```bash
npx shadcn@latest add @mapcn/delivery-tracker
```

## Dependencies

- lucide-react

## Registry Dependencies

- @mapcn/map
- card
- badge
- button

- src/registry/blocks/delivery-tracker/page.tsx -> app/delivery/page.tsx (registry:page)
- src/registry/blocks/delivery-tracker/data.ts -> app/delivery/data.ts (registry:component)
