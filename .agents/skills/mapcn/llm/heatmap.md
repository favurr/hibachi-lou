# Heatmap

Globe-projected heatmap visualizing earthquake density with zoom-dependent styling.

Type: `registry:block`
Registry item: <https://mapcn.dev/r/heatmap.json>

## Install

```bash
npx shadcn@latest add @mapcn/heatmap
```

## Dependencies

None
