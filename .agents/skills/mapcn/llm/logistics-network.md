# Logistics Network

Domestic logistics map with a sidebar of stats.

Type: `registry:block`
Registry item: <https://mapcn.dev/r/logistics-network.json>

## Install

```bash
npx shadcn@latest add @mapcn/logistics-network
```

- lucide-react

- separator
